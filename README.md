# Basic Website Design Using HTML & CSS

## 📌 Project Overview
This project is a basic website developed using HTML and CSS. It demonstrates the fundamentals of webpage structure, styling, and layout design.

## 🚀 Features
- Website header with a title.
- Navigation bar with Home, About, and Contact links.
- Main content section.
- Social media links (Facebook, Instagram, and YouTube).
- Help button.
- Footer section.

## 🛠️ Technologies Used
- HTML5 – For creating the website structure.
- CSS3 – For styling and layout design.

## 📂 Project Structure
```text
Basic-Website/
│
├── website3.html
├── style.css
└── README.md
```

## 🎯 What I Learned
- Understanding HTML elements and webpage structure.
- Applying CSS properties for styling.
- Creating navigation bars and webpage sections.
- Using classes and IDs in CSS.
- Linking external CSS files to HTML.

## ▶️ How to Run
1. Download or clone this repository.
2. Keep `website3.html` and `style.css` in the same folder.
3. Open `website3.html` in any web browser.
